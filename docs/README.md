## Quick Reference

### Workflow Files
Located in `.github/workflows/`:
- `upgrade-provider.yml` - Daily check for new upstream versions
- `auto-release.yml` - Creates version tags
- `release.yml` - Builds and publishes packages (autogenerated)
- `notify-release.yml` - Sends Slack notifications

### Release Flow
```
New Terraform Provider Released
    ↓
upgrade-provider.yml (creates PR + merge)
    ↓
auto-release.yml (creates tag)
    ↓
release.yml (publishes to PyPI, npm, NuGet)
    ↓
notify-release.yml (Slack notification)
```

### Key Labels
- `needs-release/patch` - For patch releases (0.11.30 → 0.11.31)
- `needs-release/minor` - For minor releases (0.11.x → 0.12.0)
- `needs-release/major` - For major releases (0.x.x → 1.0.0)

## Important Notes

⚠️ **Do not modify `release.yml` directly** - It is autogenerated by Pulumi's ci-mgmt tool and will be overwritten.

✅ **Modify these files:**
- `.github/workflows/upgrade-provider.yml`
- `.github/workflows/auto-release.yml`
- `.github/workflows/notify-release.yml`
